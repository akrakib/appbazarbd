## 🚀 কিভাবে ব্যবহার করবেন?

### নতুন App যোগ করতে:

`index.html` ফাইলে `const APPS = [...]` array-এ নিচের format এ যোগ করুন:

```javascript
{
  name: "App Name",           // অ্যাপের নাম
  icon: "🎬",                 // emoji icon
  imgSrc: "data:image/...",   // logo (optional — base64)
  cat: "video",               // video / social / games / streaming / tools
  platform: "android",        // android / windows / both
  desc: "অ্যাপের বিবরণ",      // সংক্ষিপ্ত বিবরণ
  link: "https://..."         // MediaFire / Play Store / Google Drive লিংক
}
```

### Download Link Types (Auto-detected):
| Link Source | Button Text |
|---|---|
| `play.google.com` | ▶ Play Store থেকে ডাউনলোড করুন |
| `drive.google.com` | 💾 Google Drive থেকে ডাউনলোড করুন |
| `mediafire.com` | 📥 MediaFire থেকে ডাউনলোড করুন |
